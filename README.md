# DesignAgent

Open-source AI agent that controls Photoshop, CorelDRAW, Figma and free
alternatives locally on your PC. Operated via Telegram from your phone.
Bring your own API key. Zero data stored. Zero cloud dependency.

## Status
🚧 Active development — v0.1.0

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your keys
3. `pip install -r requirements.txt`
4. `python main.py`

## Supported AI Providers
- Groq (free tier)
- Google Gemini (free tier)
- Anthropic Claude
- OpenAI
- OpenRouter
- Ollama (fully offline, no key needed)

## Supported Design Apps
- Adobe Photoshop
- CorelDRAW
- GIMP (free)
- Inkscape (free)
- Krita (free)
- Figma
